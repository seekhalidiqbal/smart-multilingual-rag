# Smart Multilingual AI RAG Assistant

A Smart Multilingual Retrieval-Augmented Generation (RAG) Assistant developed as an MSCS research project at the University of Okara.

## Features

- Multilingual question answering
- Multiple document upload
- PDF, DOCX, TXT, CSV and PPTX support
- Semantic search using FAISS
- Multilingual embeddings
- Context-aware retrieval
- File-specific retrieval
- Multi-document comparison
- Exact information retrieval
- Source and page references
- Groq Llama language model
- Gradio web interface

## Technologies

- Python
- LangChain
- FAISS
- Hugging Face Sentence Transformers
- Groq Llama
- Gradio

## Supported Documents

- PDF
- DOCX
- TXT
- CSV
- PPTX
